# Alphade

自分の動画から半透明の透かし、ロゴ、文字の重ね合わせを Mac 上で取り除きます。Alphade はぼかしてごまかすのではなく、下にあった元の映像を取り戻します。

[English](README.md) | [Deutsch](README-de.md) | [Español](README-es.md) | [Français](README-fr.md) | 日本語 | [한국어](README-ko.md) | [繁體中文](README-zh_TW.md)

![オリジナルと処理後の映像を並べて比較する Alphade](images/compare.png)

## できること

透かしの周りを枠で囲むだけです。Alphade は動画全体を解析して透かしがどのように重ねられたかを割り出し、全フレームでそれを逆算して元に戻します。不透明な透かしが単純な背景の上にある場合は、周囲の背景からなめらかに埋めます。

- **ぼかさずに復元**：半透明の透かしを映像から取り除くので、下にあった内容がそのまま現れます。
- **書き出す前に結果がわかる**：解析が終わると、その透かしが「きれいに除去可能」「除去可能（背景で埋める）」「除去後にぼやける」のどれになるかを表示します。
- **すべてのフレームを確認できる**：1 フレームずつ確認したり、オリジナルと左右に並べて比較したり、好きな位置から再生したりできます。
- **変わるのは枠の中だけ**：元の解像度のまま、または 1080p、720p に縮小して、H.264 か HEVC で書き出せます。音声はそのままコピーします。
- **プライバシー**：処理はすべて Mac 上で行います。動画をアップロードすることはなく、アカウントも不要です。Alphade はネットワークに接続せず、データも一切収集しません。
- **無料**。

## インストール

macOS 26 以降が必要です。Apple シリコン搭載の Mac で動作を確認しています。Alphade は Developer ID で署名され、Apple の公証を受けています。

### ダウンロード

1. [最新リリース](../../releases/latest)から [`Alphade.zip`](../../releases/latest/download/Alphade.zip) をダウンロードします。
2. zip を開き、**Alphade** を「アプリケーション」フォルダにドラッグします。
3. Alphade を開きます。インターネットからダウンロードしたアプリを開くか macOS に確認されたら、「開く」をクリックします。

アンインストールするには、Alphade をゴミ箱にドラッグします。設定と一時ファイルは `~/Library/Containers/app.vulcanshen.alphade` にあり、こちらも削除できます。

### Homebrew

```sh
brew install --cask vulcanshen/tap/alphade
```

アップデートは `brew upgrade --cask alphade`、アンインストールは `brew uninstall --cask alphade` です。`--zap` を付けると設定と一時ファイルも削除します。

## はじめかた

1. **動画を選択…** をクリックします（ウインドウに動画をドロップしても構いません）。
2. 透かしの周りに、四辺とも少し余裕を持たせて枠をドラッグします。
3. **解析** をクリックします。
4. **オリジナル**、**処理後**、**比較** で結果を確認します。
5. **書き出す…** をクリックして保存先を選びます。ファイル名には `<元のファイル名>_nowm.mp4` が入力されています。

表示言語はシステムの言語に従います（English、Deutsch、Español、Français、日本語、한국어、繁體中文）。設定で切り替えることもできます。

## キーボード

| キー | 操作 |
|---|---|
| ⌘O | 動画を開く |
| ⌘E | 書き出す |
| ⌘1 / ⌘2 / ⌘3 | オリジナル／処理後／比較 |
| ← / → | 前のフレーム／次のフレーム |
| スペース | 再生または一時停止（消音） |
| O を押し続ける | 押している間オリジナルを表示 |
| ⌘+ / ⌘− | 拡大／縮小（枠を描いたあと） |
| ⌘, | 設定（言語） |

## 得意なもの

- 動画全体を通して同じ位置にある半透明の透かし、ロゴ、文字
- 単色、グラデーション、スライドなど単純な背景の上にある不透明なロゴ
- 8 ビット（SDR）の MP4、MOV、M4V 動画

## 対応していないもの

- 動いたり位置が変わったりする透かし
- 細かい背景や実写映像の上にある不透明な透かし（その部分がぼやけます）
- 10 ビットおよび HDR の動画

## 自分の動画に使ってください

編集するのは、自分が所有している動画か、変更する許可を得ている動画だけにしてください。他人の透かしを取り除くと、お住まいの地域の著作権法に違反するおそれがあります。Alphade をどう使うかはご自身の責任です。
